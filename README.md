## Overview

**AI Health Copilot** is an end-to-end intelligent health assessment platform that fuses classical machine learning with modern generative AI agents.

It demonstrates the full CRISP-DM lifecycle and the practical integration of trained models into agentic workflows — exactly as taught in Chapter 10 of the handbook.

### Core Capabilities

| Capability | Description |
|------------|-------------|
| **Predictive Health Analytics** | Risk assessment for diabetes, heart disease and Parkinson’s using validated scikit-learn models |
| **Intelligent Diagnosis Explanations** | LLM-powered natural language explanations of contributing risk factors |
| **Personalized Wellness Planning** | Dynamic diet & fitness recommendations generated by the agent |
| **Full-Stack Delivery** | Modern React + TypeScript frontend with Python ML backend |
| **Production Patterns** | Model training, serialization, inference API, evaluation metrics and agent orchestration |

## Quick Start

### 1. Clone the repository

```bash
git clone https://github.com/Harrypatria/Masterclass-Batch-10-Health-AI-Agent.git
cd Masterclass-Batch-10-Health-AI-Agent
```

### 2. Python environment (ML + Agent backend)
```Bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Frontend (optional but recommended)
```Bash
npm install
npm run dev
```


### 4. Environment variables
Create a .env file in the project root (never commit real keys):
envOPENAI_API_KEY=your-openai-key
GOOGLE_API_KEY=your-gemini-key

### 5. Run the health copilot
```Bash
# Train / retrain models (optional)
python backend/train.py

# Start the agent service
python backend/main.py
```
